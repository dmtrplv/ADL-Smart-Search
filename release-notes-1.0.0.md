# ADL Smart Search 1.0.0

Первый стабильный релиз. Главное по сравнению с 0.9.1 — заметно более простая и предсказуемая работа с настройками, обновлённый dev-режим и доработки поиска.

## Настройки и dev-режим

- Убраны пользовательские overrides. Теперь есть ровно один источник настроек — `config/` проекта при запуске из Python или подключённого репозитория при запуске exe. Наружу вынесен только путь к репозиторию.
- Dev-панель работает по модели «черновик + явное сохранение»: изменения применяются сразу, но в `settings.json`, `llm.json` и `prompts.json` попадают только по кнопке «Сохранить». Добавлены общие «Сохранить всё» и «Сбросить всё», у каждого блока есть свои «Сохранить» и «Сбросить».
- В dev-режиме exe кнопки сохранения пишут в тот же `config/` репозитория, который читают пользователи. Устаревшие `*.overrides.json` удаляются при старте.
- Явный переключатель **«Размышления (thinking)»** показывается только для моделей, которые его поддерживают.
- Бюджет контекста для ИИ перенесён в блок «LLM» и хранится в `config/llm.json`.
- Индикатор несохранённых изменений стал заметным — красным.
- Текстовые поля промптов подстраиваются по высоте под содержимое.

## Поиск и ИИ

- История запросов: до 10 последних запросов в выпадающем списке, отдельно для архетипов и полей.
- Добавлен бонус за точное словосочетание и подсветка фраз в результатах.
- Лексическое совпадение стало строже: общие префиксы слов больше не дают ложных срабатываний.
- Расширения запроса фильтруются по словарю базы: в подсказках остаются только термины, которые реально есть в индексе.
- Улучшена работа с CKM: перевод контекста по запросу, спиннер во время перевода, аккуратные подписи источников и дат индексации.
- Дубликаты local + CKM схлопываются, версии архетипов упорядочиваются предсказуемее.
- В выдаче полей показывается контекст архетипа.

## Интерфейс и стабильность

- Обновлён общий вид чата и сайдбара, добавлена иконка приложения.
- Даты сборки индексов отображаются без мигания и не перегружают карточки.
- Улучшены подсказки по пустым результатам, ошибкам и коротким токенам.
- Расширено тестовое покрытие: обновление приложения, первый запуск, dev-настройки, промпты, архивы обновлений и откат при ошибке.

## Обновление

Обновление с 0.9.1 поддерживается автоматически: приложение увидит версию 1.0.0, скачает дельту или полный архив и перезапустится. Данные и `config/` при обновлении не затрагиваются.
